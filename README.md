Overview

This project is a simple Contact Log built with a C# Console Application. It allows users to manage a list of contacts by performing basic CRUD operations. Each contact has an ID, a name, and a phone number. The application demonstrates fundamental C# programming concepts such as console input and output, collections, and object-oriented programming.

Features

The application supports creating new contacts, viewing all existing contacts, updating contact details, and deleting contacts by ID. It provides a straightforward console-based menu for navigation and interaction.
