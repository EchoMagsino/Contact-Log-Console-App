📒 Contact Log (C# Console Application)
Overview
This project is a simple Contact Log built with C# Console.
It allows users to manage a list of contacts by performing basic CRUD operations:

Create new contacts with an ID, name, and phone number

Read and display existing contacts

Update contact details

Delete contacts from the log

The goal of this project is to demonstrate fundamental C# programming concepts such as:

Console input/output

Collections (e.g., lists)

Object-oriented programming

Basic CRUD functionality

Features
Add a new contact (ID, Name, Number)

View all saved contacts

Update existing contact information

Delete a contact by ID

Simple console-based menu navigation
